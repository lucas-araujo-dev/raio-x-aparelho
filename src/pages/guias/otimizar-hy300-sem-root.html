Como deixar o HY300 mais leve sem root

O HY300 tem só ~1 GB de RAM. Cada megabyte livre faz diferença. Este é o procedimento que aplicamos e medimos, e todos os passos têm reversão.

Resultado medido

ItemAntesDepois
Memória do launcher (tela inicial)122–137 MB33 MB
Abertura da tela inicial500 ms454 ms
Loja do fabricante rodando em segundo plano12 MB, 2 serviçosdesativada
Animações1×0,5× (transições na metade do tempo)
Fuso horárioCosta Rica (relógio 3 h atrasado)São Paulo

O maior ganho é de memória, não de velocidade: ~100 MB a mais livres reduzem a chance de o YouTube recarregar quando você volta para ele.

1. Preparar o acesso (ADB por Wi-Fi)

  1. No projetor: Configurações → Preferências do dispositivo → Sobre → clique 7 vezes em Build para ativar o modo desenvolvedor.
  2. Em Opções do desenvolvedor, ative a Depuração USB. No HY300 testado, isso já abriu o ADB pela rede na porta 5555.
  3. Veja o IP do projetor em Configurações → Rede.
  4. No computador, instale as Platform Tools do Android e rode:
adb connect 192.168.0.X:5555

Autorize a conexão na tela do projetor.

2. Desativar apps de fábrica que não servem para nada

Desativar não apaga nada e pode ser desfeito. Estes eram os apps desta firmware (confira os seus com adb shell pm list packages):

adb shell pm disable-user --user 0 com.htc.storeos              # loja do fabricante
adb shell pm disable-user --user 0 com.htc.hyk_test             # teste de fábrica
adb shell pm disable-user --user 0 com.softwinner.agingdragonbox # teste de fábrica
adb shell pm disable-user --user 0 com.softwinner.dragonatt      # teste de fábrica
adb shell pm disable-user --user 0 com.softwinner.dragonbox      # teste de fábrica
adb shell pm disable-user --user 0 com.mobisystems.office        # OfficeSuite

Não desative com.htc.htcsettings (foco, keystone, Bluetooth), com.htc.closedialog (ventoinha e controle) nem com.softwinner.awlivetv (entrada HDMI).

Para reverter: adb shell pm enable NOME.DO.PACOTE

3. Animações mais rápidas

adb shell settings put global window_animation_scale 0.5
adb shell settings put global transition_animation_scale 0.5
adb shell settings put global animator_duration_scale 0.5

Para reverter, use 1.0 no lugar de 0.5.

4. Corrigir o fuso horário

O fuso automático deste firmware escolhia a Costa Rica. Para fixar o horário de Brasília:

adb shell settings put global auto_time_zone 0
adb shell cmd alarm set-timezone America/Sao_Paulo

5. Trocar a tela inicial por uma leve

Launchers bonitos, cheios de banners e recomendações, são os maiores consumidores de memória do aparelho. Prefira um launcher simples, só com a grade de apps. Depois de instalar, defina como padrão pela própria tela (botão Home → escolher) ou por ADB:

adb shell cmd package set-home-activity PACOTE/.Atividade

6. Reiniciar e conferir

adb reboot
adb shell dumpsys meminfo | grep -E "Total RAM|Free RAM|Used RAM"

No nosso teste, tudo persistiu após reiniciar (boot em ~46 s).

Antes de tudo: o seu é mesmo um H713?

Existem várias placas vendidas com o mesmo nome. Rode o Raio-X no navegador do projetor: se aparecer GPU Mali-G31 e 32 bits, este guia vale para você.
